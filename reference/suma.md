# Sumar dos numeros

Suma dos valores numericos no negativos.

## Usage

``` r
suma(x = 0, y = 0)
```

## Arguments

- x:

  Primer numero. Por defecto es 0.

- y:

  Segundo numero. Por defecto es 0.

## Value

La suma de los numeros o un mensaje si alguno es negativo.

## Examples

``` r
suma(3, 4)
#> [1] 7
suma()
#> [1] 0
suma(-2, 5)
#> [1] "No puedo sumar negativos"
```
