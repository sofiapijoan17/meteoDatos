# Temperaturas de ejemplo

Conjunto de cinco temperaturas utilizado para practicar el manejo de
datos en el paquete meteoDatos.

## Usage

``` r
temperaturas
```

## Format

Vector numerico con 5 valores.

## Source

Datos ficticios creados para Programacion II.

## Examples

``` r
data("temperaturas")
temperaturas
#> [1] 20 22 25 18 24
```
