# Calcular el promedio de dos temperaturas

Calcula el promedio de dos valores de temperatura.

## Usage

``` r
promedio_temperaturas(temp1, temp2)
```

## Arguments

- temp1:

  Primera temperatura.

- temp2:

  Segunda temperatura.

## Value

El promedio de las dos temperaturas.

## Examples

``` r
promedio_temperaturas(20, 30)
#> [1] 25
```
