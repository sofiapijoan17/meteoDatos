
# Código de conducta

## Nuestro compromiso

Como integrantes y colaboradoras del proyecto meteoDatos, nos comprometemos a mantener un ambiente respetuoso, inclusivo y colaborativo para todas las personas que participen.

## Comportamientos esperados

- Tratar a todas las personas con respeto y amabilidad.
- Escuchar opiniones diferentes y aceptar críticas constructivas.
- Dar crédito al trabajo de otras personas.
- Comunicarse de manera clara y respetuosa.
- Colaborar para resolver problemas y mejorar el proyecto.

## Comportamientos inaceptables

No se tolerarán insultos, acoso, discriminación ni conductas que perjudiquen a otras personas.

## Responsabilidad

Las responsables del proyecto podrán revisar situaciones que incumplan estas pautas y tomar medidas para mantener un entorno de trabajo respetuoso.

## Alcance

Este código se aplica a las interacciones relacionadas con el proyecto meteoDatos, tanto dentro como fuera del repositorio.
