# Guía de contribución

Gracias por colaborar con meteoDatos.

## Cómo contribuir

1.  Revisar los archivos y las funciones existentes antes de realizar
    cambios.
2.  Crear una rama para trabajar en una mejora o corrección.
3.  Realizar cambios pequeños y relacionados con un único objetivo.
4.  Agregar o actualizar los tests cuando se modifiquen las funciones.
5.  Actualizar la documentación si cambia el comportamiento del paquete.
6.  Ejecutar los tests antes de enviar los cambios.
7.  Utilizar mensajes de commit claros y descriptivos.

## Estilo de código

- Utilizar nombres descriptivos para funciones y variables.
- Mantener un formato consistente en el código R.
- Documentar las funciones con roxygen2.
- Incluir ejemplos de uso cuando corresponda.

## Revisión de cambios

Antes de integrar los cambios a la rama principal, comprobar que los
tests funcionen correctamente y que las GitHub Actions no informen
errores.

## Trabajo en equipo

Las integrantes deben comunicar los cambios realizados, revisar el
trabajo de la otra persona y reconocer las contribuciones de cada
integrante.
